# Yixuan Guan

I'm a PhD student in mechanical engineering (robotics) at Tsinghua University, working on robot perception and manipulation. I also develop game-playing agents and open-source software.

## Research

**[DexSim2Real²](https://jiangtaoran.github.io/dexsim2real2web/)** — *IEEE T-RO, 2025 · Co-first author*

Designed and implemented the explicit world-model construction pipeline, reconstructing articulated objects from multi-view observations into simulation-ready URDF models.

**[AllTact Fin Ray](https://arxiv.org/abs/2504.18064)** — *IEEE T-ASE, 2025 · Co-first author*

Developed the visual-tactile processing pipeline, including marker detection and tracking, cross-frame matching, occlusion handling, and real-time multiprocessing.

## Featured Projects

**[pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft) & [pyCapCut](https://github.com/GuanYixuan/pyCapCut)** — Python libraries for programmatic draft generation and editing in Jianying and CapCut.

Built structured APIs around drafts, tracks, and segments, enabling scripted video-editing workflows.

**[Kaggle Lux AI Season 3](https://github.com/GuanYixuan/NIPS2024-LuxSeason3)** — Planning and search in a partially observable game.

Independently built an agent using state estimation, task allocation, and weighted A* search. Silver Medal, 27th of 701 on [Kaggle leaderboard](https://www.kaggle.com/competitions/lux-ai-season-3/leaderboard).
